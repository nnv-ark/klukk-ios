# What's New — KLUKK! 1.3

Set on App Store Connect version 1.3, in en-US (primary) and en-GB
(Apple has no Icelandic storefront locale, so the combined EN+IS text is used).

---

KLUKK! now speaks Icelandic!
Full Icelandic localization — the whole app, including the widget and the target-time picker. Switch in Settings → Language.

Nú talar KLUKK! íslensku!
Allt appið er á íslensku — einnig widgetið og marktímavalinn. Skiptu um tungumál í Stillingar → Tungumál.

Also: the target-time wheel now shows klst / mín correctly in every language.
